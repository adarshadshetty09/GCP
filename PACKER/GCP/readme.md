
# working

# In Google Cloud, 
# OAuth scopes control what resources a VM or service account can access using Google APIs.
# They act like permission filters on top of the IAM roles your service account already has.



# | Scope URL                                                 | Purpose                                                              |
# | --------------------------------------------------------- | -------------------------------------------------------------------- |
# | `https://www.googleapis.com/auth/compute`                 | Manage Compute Engine resources                                      |
# | `https://www.googleapis.com/auth/devstorage.full_control` | Full access to Cloud Storage                                         |
# | `https://www.googleapis.com/auth/userinfo.email`          | Read the email address of the service account                        |
# | `https://www.googleapis.com/auth/cloud-platform`          | **Full access to all GCP services** (recommended for most use cases) |
